# Agent Token Budget

## Principle

优先使用确定性程序处理机械任务，
将LLM调用留给需要理解、判断和生成的任务。

## 不应该调用LLM的任务

- 文件是否存在
- 文件格式检查
- 标题检查
- 字段检查
- 字符统计
- 重复检查
- 简单计算
- 状态枚举检查
- 固定规则校验

## 应该调用LLM的任务

- 需求理解
- 业务规则识别
- 歧义分析
- 风险判断
- 问题优先级判断
- 自然语言报告生成

## Cost Awareness

每增加一次LLM调用，都应该有明确价值。

优先：

一次高质量分析
+
程序化验证

而不是：

多次重复让LLM检查同一内容。
