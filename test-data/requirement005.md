# Requirement 005

## 1. 背景

客户提交贷款申请后，系统可能会发现申请资料不完整，此时需要提示客户补充资料，避免因资料缺失导致审批无法进行。

## 2. 目标

让客户能够在资料不完整时收到提示并完成补充，确保只有资料完整的申请才能进入审批流程。

## 3. 范围

### 3.1 本次覆盖

- 系统检测贷款申请资料是否完整
- 资料不完整时提示客户补充
- 客户通过手机端补充资料并重新提交
- 后台工作人员查看客户提交的资料
- 工作人员在资料仍不完整时要求客户再次补充
- 资料完整后，申请进入审批流程

## 4. 功能点

1. **资料完整性检测**
   - 功能描述：客户提交贷款申请后，系统检查申请资料是否完整。
   - 涉及角色：系统（自动检测）

2. **资料不完整提示**
   - 功能描述：当资料不完整时，提示客户补充资料。
   - 涉及角色：客户

3. **客户补充资料**
   - 功能描述：客户可以通过手机端补充资料。
   - 涉及角色：客户

4. **重新提交申请**
   - 功能描述：客户补充资料后，可以重新提交申请。
   - 涉及角色：客户

5. **工作人员查看资料**
   - 功能描述：后台工作人员可以查看客户提交的资料。
   - 涉及角色：后台工作人员

6. **要求再次补充**
   - 功能描述：如果资料仍然不完整，工作人员可以要求客户再次补充。
   - 涉及角色：后台工作人员

7. **进入审批流程**
   - 功能描述：资料完整后，申请进入审批流程。
   - 涉及角色：待确认（审批流程的具体角色业务描述未说明）

## 6. 验收标准

- 客户提交贷款申请后，若资料不完整，能收到补充提示
- 客户能够通过手机端完成资料补充并重新提交
- 资料补充后，系统能够重新判断资料是否完整
- 资料完整后，申请状态进入审批流程
- 后台工作人员能够查看客户提交的资料
- 工作人员可以在资料仍不完整时要求客户再次补充
