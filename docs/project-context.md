# Project Context

## Project

Requirement Generation & Review Agent

## User

产品经理。

## Purpose

输入一段业务描述，帮助产品经理生成结构化业务需求文档，
并快速发现需求中的核心歧义、缺失业务规则和设计风险。

## Domain

主要面向：

- 银行
- 信贷
- 医院
- 企业内部系统

## Output

结构化业务需求文档（PRD） + 对应的结构化需求评审报告。

## Principle

Agent不是业务规则的创造者。

Agent的职责是：

发现问题，
解释为什么重要，
指出需要向业务确认什么。
